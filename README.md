# Login and Registration System

## Project Description
The Login and Registration System is a C++ console-based application developed as part of the CodeAlpha C++ Programming Internship. It allows users to register accounts and log in using their usernames and passwords.

## Features
- User registration.
- Username and password input.
- Basic input validation.
- Duplicate username checking.
- Store user credentials in a file.
- Login authentication.
- Success and error messages.

## Programming Language
- C++

## Concepts Used
- Functions
- Conditional Statements
- Loops
- File Handling
- Strings
- Input and Output

## How to Run
1. Download or clone this repository.
2. Open `Login_System.cpp` in Code::Blocks or Dev-C++.
3. Compile the program.
4. Run the application.
5. Register an account and then log in.
